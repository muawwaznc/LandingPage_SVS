Smart Ventilation System

A smart IoT-powered solution designed to ensure healthy indoor air quality. The system detects CO₂, humidity, temperature, and dust levels — automatically controlling fans and windows for ideal ventilation. About the Project

The Smart Ventilation System is a student-led IoT innovation from the Department of Computer Engineering, UET Lahore. It automatically manages indoor air quality using intelligent sensors and cloud connectivity. The mobile application serves as the main interface — giving users real-time monitoring, alert notifications, and control over ventilation devices.

IoT-Enabled Sensors

Collects real-time data on CO₂, temperature, humidity, and dust levels to maintain optimal indoor conditions.

Smart Mobile App

The mobile app allows users to visualize data, receive alerts, and control ventilation systems manually or automatically.

Cloud & Weather Integration

Stores all readings securely on a cloud platform and integrates outdoor weather data for smarter ventilation control.
